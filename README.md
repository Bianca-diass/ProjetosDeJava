# Projetos De Java

Coleção de projetos e pequenos programas desenvolvidos em Java para práticas de programação e lógica.

## 🚀 Tecnologias
* **Java**

## 📁 Conteúdo do Repositório

* `AgendaContatos.Java` - Aplicação para gestão e organização de contactos.
* `BlocoNotas.Java` - Bloco de notas simples para criação e edição de texto.
* `JogoAdivinhacao.Java` - Jogo interativo de adivinhação de números.
* `QuizPerguntas.Java` - Jogo de perguntas e respostas (Quiz).
* `SistemaBiblioteca.Java` - Sistema para controlo e gestão de livros/biblioteca.
